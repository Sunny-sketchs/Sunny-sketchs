### 🚀 Featured Projects

**[SQL-RAG-Analyst](https://github.com/Sunny-sketchs/SQL-RAG-ANALYST)** — Hybrid SQL + RAG analytics agent
A LangGraph-routed agent that answers questions over structured sales data *and* unstructured policy
docs, picking (or combining) the right tool automatically. SQL-injection-hardened, provider-swappable
(OpenAI/Gemini), and backed by a 50-question eval harness that took accuracy from 76% → 84% through
three logged, evidence-driven bug fixes.
`FastAPI` `LangGraph` `PostgreSQL/pgvector` `Streamlit`

**[Guardrailed LLM Gateway](https://github.com/Sunny-sketchs/LLM-Gateway)** — Safety & cost-control proxy for LLM APIs
Sits in front of an LLM API and checks every request — token limits, rate limiting, caching, prompt-injection
detection, PII redaction — cheapest-check-first, before any billed API call happens. Includes custom PII
recognizers for Indian phone numbers and PAN, and full request auditing to Postgres.
`FastAPI` `Redis` `PostgreSQL` `Microsoft Presidio`

**[Histopathology Tumor Patch Classifier (PCam)](https://github.com/Sunny-sketchs/Tumor-classifier)** - A binary classifier that predicts whether a 96x96 histopathology image patch contains
tumor tissue, built with transfer learning on ResNet18, evaluated with a controlled
frozen-vs-fine-tuned comparison, and analyzed with Grad-CAM interpretability and
error analysis.


**[TableForge](https://github.com/Sunny-sketchs/Table_Forge)** — High-concurrency data intelligence platform
Extracts complex tabular data from PDFs (even ruled, image-based ones) and lets users query it in natural
language via Gemini. Offloads heavy PDF parsing to background threads with `asyncio.to_thread` so the
FastAPI backend stays responsive during long-running extraction jobs, with a React dashboard for real-time
status polling.
`FastAPI` `Camelot-Py` `PostgreSQL` `Gemini API` `React`
